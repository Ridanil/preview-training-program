# Макет: программы курсов плитками

Статический предпросмотр страницы `/education/training/program/` (сайт langnat.local не изменён).

- Плитки оформлены по образцу раздела `/projects/`: карточка со скруглением, тенью при наведении, сетка 3/2/1 колонки.
- Вместо изображения в плитке выведено название программы (классы `t-1 my-2 t-title с-text-primary l-inherit l-hover-primary l-hover-underline-none transition`).
- Клик по плитке ведёт на страницу программы (`/education/training/program/<символьный-код>/`).
- Стили и скрипты сайта берутся из `../preview-department/assets/`.
- Шапка, меню и подвал упрощённые, для проверки вёрстки списка.
